# Validation

Un changement urgent nécessite la validation du
[coordinateur de crise](/roles/coordinateur-crise.md). La validation peut être
orale ; elle est consignée dans le ticket dans l'heure qui suit.[^cr-incident-0917]

# Traçabilité

Le motif d'urgence et le numéro de l'incident lié doivent être consignés dans le
ticket de changement.
