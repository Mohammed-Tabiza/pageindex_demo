# Missions

Le coordinateur de crise prend le relais lorsque le responsable d'astreinte ne
répond pas sur un incident P1 réel. Il ouvre le pont de crise et désigne le pilote.

# Contact

Le coordinateur de crise est joint par l'outil d'appel d'astreinte, groupe
« Crise Orion ». Aucun numéro de téléphone personnel n'est publié dans ce bundle.
